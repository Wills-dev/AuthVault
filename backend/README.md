# Backend boundary

Phase 3 will initialize NestJS here with TypeScript strict mode, Prisma and PostgreSQL.
No backend server or successful authentication responses exist in Phase 1.

Planned modules: Auth, Users, Biometric, Otp, Mail, Logging, Prisma.
See ../docs/architecture.md and ../docs/api-contract.md before implementation.
Exact NestJS, Prisma, JWT, Argon2id, Nodemailer and Jest versions will be resolved,
compatibility checked and locked when the backend is introduced. Node 24.22.1 is
available; no global Nest CLI is required.
